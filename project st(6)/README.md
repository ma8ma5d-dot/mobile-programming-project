# پاسخ تمرین‌های عملی Flutter

این پروژه شش تمرین را در قالب یک برنامه Flutter قابل اجرا گردآوری کرده است.

## تمرین‌ها

1. **اپلیکیشن دوصفحه‌ای:** صفحه اول دکمه دارد و با کلیک روی آن صفحه دوم باز می‌شود و نام دانشجو را نمایش می‌دهد.
2. **فرم ورود:** نام کاربری اجباری است و رمز عبور باید حداقل ۸ کاراکتر داشته باشد. پس از معتبر بودن ورودی‌ها پیام موفقیت نمایش داده می‌شود. این نمونه آموزشی است و به سرور احراز هویت متصل نیست.
3. **فرم ثبت اطلاعات دانشجو:** نام، شماره دانشجویی، رشته، تلفن و ایمیل دریافت می‌شوند و برای هرکدام اعتبارسنجی تعریف شده است.
4. **ارسال اطلاعات بین صفحات:** نام و سن دریافت و با سازنده صفحه (constructor) به صفحه پروفایل فرستاده می‌شوند.
5. **Dialog تأیید خروج:** با آیکون خروج در AppBar صفحه اصلی، پنجره تأیید نمایش داده می‌شود. برای جلوگیری از بسته‌شدن ناخواسته برنامه در محیط‌های مختلف، پس از تأیید یک پیام تأیید نمایش داده می‌شود.
6. **مدیریت دانشجو:** صفحه اصلی، فرم ثبت و صفحه جزئیات دارد. داده ثبت‌شده با `Navigator.pop(context, student)` به صفحه اصلی برمی‌گردد و در فهرست نمایش داده می‌شود. داده‌ها فعلاً فقط در حافظه برنامه هستند و با بستن برنامه دائمی نمی‌مانند.

## ساختار فایل‌ها

- `lib/main.dart`: نقطه شروع برنامه
- `lib/pages/home_page.dart`: صفحه اصلی، تمرین اول و Dialog خروج
- `lib/pages/login_page.dart`: تمرین دوم
- `lib/pages/student_registration_page.dart`: تمرین سوم
- `lib/pages/user_input_page.dart`: تمرین چهارم
- `lib/pages/student_management_page.dart`: تمرین ششم

## اجرا

1. Flutter SDK و Android Studio یا VS Code را نصب کنید.
2. فایل ZIP را استخراج کنید.
3. پوشه پروژه را در ویرایشگر باز کنید.
4. در ترمینال اجرا کنید:

```bash
flutter pub get
flutter run
```

برای بررسی کد:

```bash
flutter analyze
```

## نکته شخصی‌سازی
نام دانشجو در تمرین اول به‌صورت نمونه «محمد احمدی» درج شده است. قبل از تحویل می‌توانید نام را در `lib/pages/home_page.dart` تغییر دهید.
