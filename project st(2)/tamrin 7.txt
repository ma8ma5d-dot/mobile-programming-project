پاسخ تمرین ۶:
در Kotlin، نوع String برای متنی است که نمی‌تواند null باشد؛ اما String? یک نوع nullable است و می‌تواند شامل متن یا مقدار null باشد.

مثال:
val name: String = "Ali"
var nickname: String? = null

در خط اول باید یک متن معتبر وجود داشته باشد. در خط دوم مقدار null مجاز است، چون علامت ? نشان می‌دهد متغیر می‌تواند تهی باشد. برای استفاده ایمن از مقدار nullable می‌توان از ?. یا عملگر پیش‌فرض ?: استفاده کرد؛ مانند nickname ?: "ندارد".

پاسخ تمرین ۷:
در فایل XML یک TextView برای عنوان و یک Button برای دکمه ساخته شده است. در MainActivity با setContentView صفحه را نمایش می‌دهیم، دکمه را با findViewById پیدا می‌کنیم و با setOnClickListener رویداد کلیک را تعریف می‌کنیم. هنگام لمس دکمه، Toast پیام کوتاهی به کاربر نشان می‌دهد.

توضیح کوتاه:
- val: متغیری که پس از مقداردهی دوباره قابل انتساب نیست.
- fun: برای تعریف تابع استفاده می‌شود.
- for: برای تکرار دستورات به کار می‌رود.
- class: برای تعریف کلاس و نگهداری داده‌ها و رفتارها استفاده می‌شود.
