# پاسخ تمرین‌های عملی Flutter

این پروژه شامل چهار صفحه مستقل و یک صفحه اصلی برای باز کردن تمرین‌هاست.

## ساختار پروژه

- `lib/main.dart`: صفحه اصلی و منوی انتخاب تمرین
- `lib/screens/student_profile_page.dart`: تمرین اول؛ معرفی دانشجو با `Scaffold`، `AppBar`، `Column`، `Text` و `Icon`
- `lib/screens/advanced_counter_page.dart`: تمرین دوم؛ افزایش شمارنده و صفرکردن آن با `setState`
- `lib/screens/registration_form_page.dart`: تمرین سوم؛ دریافت نام، نام خانوادگی و رشته و نمایش نتیجه پس از ثبت
- `lib/screens/student_card_page.dart`: تمرین چهارم؛ کارت اطلاعات با `Card`، `Padding`، `Row` و `Column`

اطلاعات نام، رشته و شماره دانشجویی در صفحات نمونه هستند. قبل از تحویل، آن‌ها را با اطلاعات خود جایگزین کنید.

## تمرین پنجم: مقایسه روش‌های توسعه

| معیار | Flutter | Native با Kotlin | Apache Cordova |
|---|---|---|---|
| زبان اصلی | Dart | Kotlin (برای Android) | HTML، CSS و JavaScript |
| ساخت رابط کاربری | ویجت‌های Flutter و کدنویسی Dart | ابزارها و APIهای بومی Android مانند Jetpack Compose یا XML | صفحات وب که داخل WebView نمایش داده می‌شوند |
| مزایا | رابط کاربری یکپارچه، توسعه چندسکویی، ویجت‌های متنوع و عملکرد مناسب | دسترسی مستقیم به قابلیت‌های Android، هماهنگی زیاد با سیستم‌عامل و ابزارهای رسمی | استفاده از مهارت‌های وب، امکان استفاده مجدد از کدهای وب و شروع نسبتاً آسان برای توسعه‌دهندگان وب |
| محدودیت‌ها | نیاز به یادگیری Dart و چارچوب Flutter؛ گاهی وابستگی به افزونه‌ها برای قابلیت‌های خاص | برای iOS معمولاً به پیاده‌سازی جداگانه با Swift نیاز است؛ توسعه چندسکویی با یک کد واحد نیست | وابستگی به WebView و افزونه‌ها؛ عملکرد و تجربه کاربری ممکن است در برخی سناریوها از راهکارهای بومی ضعیف‌تر باشد |

### جمع‌بندی
- اگر هدف، ساخت برنامه Android با بیشترین هماهنگی با امکانات بومی آن باشد، Kotlin گزینه مناسبی است.
- اگر توسعه یک برنامه برای Android و iOS با رابط کاربری نسبتاً یکپارچه مدنظر باشد، Flutter گزینه قدرتمندی است.
- اگر تیم مهارت وب دارد و برنامه بیشتر فرم‌ها و صفحات ساده دارد، Cordova می‌تواند گزینه‌ای برای بررسی باشد؛ با این حال باید وضعیت نگهداری پروژه، سازگاری افزونه‌ها و عملکرد WebView بررسی شود.

## اجرای پروژه

1. Flutter SDK و یک ویرایشگر مانند Android Studio یا VS Code را نصب کنید.
2. پوشه پروژه را از حالت ZIP خارج کنید.
3. در ترمینال، وارد پوشه پروژه شوید.
4. فرمان‌های زیر را اجرا کنید:

```bash
flutter pub get
flutter run
```

برای بررسی خطاهای احتمالی نیز می‌توانید اجرا کنید:

```bash
flutter analyze
```
